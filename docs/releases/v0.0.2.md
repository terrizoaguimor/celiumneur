# CeliumNeUR v0.0.2

CeliumNeUR v0.0.2 is the invariant-complete RTL release: four 256-neuron
tiles, a 2x2 credit-based Hyphae mesh, routed configuration, concurrent
causal-window learning, and live state readback.

## Highlights

- 1,024 addressable neuron states and 1,024 addressable synapse entries.
- Explicit valid/ready ownership from ingress through fire, learning, routing,
  and egress; legal traffic is buffered, processed, or held under pressure.
- Atomic tick dispatch, queued stimulus injection, and sticky diagnostic
  witnesses for malformed traffic and pressure events.
- Routed five-flit CONFIG transactions with ordered assembly and fail-closed
  mutation behavior.
- Independent integration and learning walkers with signed saturation.
- Rebuilt architecture, demonstration, and presentation assets.

## Release evidence

- 55 golden-model tests.
- 32 cocotb RTL tests.
- 8 self-checking raw Icarus/vvp probes.
- 17/17 targeted mutants killed.
- Default-SoC Verilator `-Wall` lint with no emitted warnings.
- FIFO and router bounded model checks through depth 60.
- GF180 endpoint/router mapping plus whole-SoC coarse synthesis elaboration.
- A pinned four-source external audit with 13 tracked findings.

The hosted `simulation` workflow is required to pass on the release pull
request before publication.

## Scope boundary

The repository remains simulation- and synthesis-validated research RTL. It
does not include a placed-and-routed ASIC, FPGA bitstream, timing closure,
power characterization, physical memory macros, or silicon measurements.
